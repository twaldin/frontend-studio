# Product reference profiles

Reference products are coherent decision systems, not templates. Presets encode reusable relationships between type, neutral temperature, density, shell, data display, landing composition, and motion. Never copy logos, illustrations, proprietary assets, page structure, or branded language.

The public sites below were reviewed in July 2026 at desktop width. Re-check before changing a preset: product sites evolve.

## Researched profiles

### Ramp — <https://ramp.com/>

**Observed pattern.** A minimal white navigation and enormous “Time is money. Save both.” claim sit above email capture and a live operational product stage. Acid green appears only where action or live processing needs signal; fine rules and tiny uppercase measurement copy make the surface feel financial rather than decorative.

**Reuse.** High contrast, compact controls, top navigation, borderless operational data, a strong numeric/progress proof layer, heavy display type, and a full-width product stage. Keep green scarce so it reads as action. Avoid turning every datum into a card.

**Preset anchors.** `neutral / high / green / sharp / compact / topnav / strip / borderless / editorial / heavy / media / grid / bento / numbers / email`.

### Apple — <https://www.apple.com/>

**Observed pattern.** Navigation disappears behind product storytelling: centered product names and short claims lead into enormous media. Repeated full-width chapters use sparse paired actions, deep whitespace, precise crops, and motion that reveals product material rather than UI chrome.

**Reuse.** System type, giant display scale, high contrast, pill-like CTA geometry, comfortable spacing, product-led media, full-bleed or scene-chapter rhythm, and little generic social proof. Use only when the product artifact can carry the page.

**Preset anchors.** `system / neutral / high / blue / pill / comfortable / editorial / giant / media / ambient / flat / chapters / none`.

### Raindrop — <https://www.raindrop.ai/>

**Observed pattern.** A dark lowercase claim introduces a real agent observability interface. Green marks detection/resolution; traces, summaries, and evidence cards transition through a pinned product scene. The motion explains how an issue moves from observation to prevention.

**Reuse.** Dark neutral shell, compact data surfaces, one green signal, lowercase heavy display, bare product frame, interactive/scroll motion, and sticky scene-to-card chapters. Best for tools whose causal chain matters more than a generic dashboard overview.

**Preset anchors.** `neutral / standard / green / compact / sidebar / strip / chart / dark / heavy / lowercase / shot / interactiveScroll / chapters / characters / numbers`.

### Mercury — <https://mercury.com/>

**Observed pattern.** Banking is presented with warm editorial restraint: large composed type, spacious groupings, muted imagery, and product explanations that emphasize confidence over dashboard density. CTAs and proof are present without shouting.

**Reuse.** Instrument-like friendly sans, warm neutral, soft contrast, generous rhythm, subtle shadow, inline financial facts, giant editorial display, grain/media, alternating sections, and quote proof.

**Preset anchors.** `instrument / warm / soft / orange / round / shadow / comfortable / airy / editorial / giant / media / grain / alternating / quotes`.

### Cash App — <https://cash.app/>

**Observed pattern.** Black, white, and bright green build immediate recognition. Giant declarative type, mobile device imagery, large round geometry, and continuous media prioritize a consumer action over feature taxonomy. Proof is numeric and the CTA is singular.

**Reuse.** High contrast, green accent, 16px control radius, comfortable mobile-first density, giant display, device hero, full-bleed rhythm, phone frame, abstract shapes, numeric proof, and one CTA. Reserve this register for a simple consumer action.

**Preset anchors.** `system / neutral / high / green / pill / comfortable / playful / giant / device / ambient / fullbleed / phone / numbers / single`.

### Airbnb — <https://www.airbnb.com/>

**Observed pattern.** Search is the primary object. Warm white space, soft elevation, round search controls, photographic inventory, compact metadata, and generous touch targets make browsing feel comfortable. The product's supply is the visual identity.

**Reuse.** Warm neutral, coral/crimson action color, pill controls, comfortable density, top navigation, filled cards, media-led hero, bento inventory rhythm, and proof through real listings or quotes. Photography must be real and useful, not decorative stock.

**Preset anchors.** `system / warm / soft / crimson / pill / soft / comfortable / topnav / fill / playful / heavy / media / bento / quotes`.

### Figma — <https://www.figma.com/>

**Observed pattern.** The public site uses giant statements, bold geometry, multiple saturated colors, and interactive demonstrations that behave like a creative canvas. Underneath, the product UI remains dense and tool-like.

**Reuse.** High-contrast base, controlled orange signal, standard app density, strong display scale, media or interactive hero, scene background, bento rhythm, browser frame, and abstract product geometry. Let interaction demonstrate creation rather than adding ambient confetti.

**Preset anchors.** `inter / neutral / high / orange / round / standard / topnav / playful / giant / media / interactive / scene / bento / shapes`.

### Cursor — <https://cursor.com/>

**Observed pattern.** Warm near-black surfaces and restrained typography frame a clear coding claim and authentic editor/agent proof. Product evidence is readable; decoration is subordinate. Large type feels editorial without abandoning developer precision.

**Reuse.** Geist-like sans/mono pairing, warm dark neutral, compact sidebar tool, dense rows, heavy direct claim, grid, bare product shot, and logo proof. Use for developer products where the working artifact can be shown clearly.

**Preset anchors.** `geist / geist-mono / warm / neutral accent / compact / tight / sidebar / dark / heavy / shot / ambient / grid / alternating`.

### Supabase — <https://supabase.com/>

**Observed pattern.** A dark developer platform uses green as an operational signal, strong grid structure, code/data product shots, and modular explanations. Dashboard, database, and docs evidence establish breadth without abandoning one technical visual vocabulary.

**Reuse.** Cool neutral, green accent, compact sidebar dashboard, hairline data tables, chart evidence, dark grid landing, framed product shot, bento sections, and logo proof. Use grid as structure, not wallpaper.

**Preset anchors.** `inter / jetbrains / cool / green / compact / tight / sidebar / chart / dark / heavy / shot / grid / bento / browser`.

### PostHog — <https://posthog.com/>

**Observed pattern.** Dense product analytics are offset by a warm canvas, orange action color, hand-drawn character energy, and product cards that explain a broad suite. Personality appears around real screenshots and metrics, not instead of them.

**Reuse.** Warm neutral, orange accent, compact sidebar application, chart-forward data, playful landing register, grain, bento, browser product frames, character pieces, and numeric proof. Keep illustration subordinate to the analytical question.

**Preset anchors.** `inter / jetbrains / warm / orange / compact / sidebar / chart / playful / heavy / shot / ambient / grain / bento / characters / numbers`.

### Attio — <https://attio.com/>

**Observed pattern.** Monochrome editorial restraint frames a highly structured CRM: sharp lines, compact tables, record relationships, and precise product copy. The hierarchy comes from spacing and type before color or shadow.

**Reuse.** High-contrast neutral, sharp corners, hairlines, compact data, borderless tables, restrained product shot, editorial register, and alternating claims. Useful when relational information and composability are the product.

**Preset anchors.** `inter / geist-mono / neutral / high / neutral accent / sharp / compact / sidebar / borderless / editorial / heavy / shot / flat / alternating`.

### Resend — <https://resend.com/>

**Observed pattern.** Dark monochrome infrastructure branding combines concise developer copy, code/email artifacts, tight navigation, and a fine grid. Product credibility comes from legible technical evidence and simplicity.

**Reuse.** Geist sans/mono, high-contrast dark theme, compact density, top navigation, outline controls, split hero, grid, browser/code frame, modular bento, and logo proof. Avoid extra accent hues unless the product state needs them.

**Preset anchors.** `geist / geist-mono / neutral / high / neutral accent / compact / tight / topnav / dark / heavy / split / entrance / grid / bento / browser`.

## Choosing a reference

Choose by structural similarity before visual taste:

1. task frequency and information density;
2. shell and primary object;
3. trust posture and audience;
4. evidence available for the landing page;
5. only then type, color, motion, and personality.

A preset recommendation must name what transfers and what does not. For example: “Use Attio's compact relational hierarchy, but not its monochrome accent because this product needs status separation.” Record every deviation in the exported decisions.
